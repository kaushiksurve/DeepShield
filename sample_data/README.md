# Sample Data

Place sample video files here for testing.

Recommended test videos:
- `sample_genuine.mp4` — A real unmanipulated video
- `sample_suspicious.mp4` — A video with audio-visual inconsistencies
- `sample_deepfake.mp4` — A known deepfake for testing

Note: Sample files are not included in this repository due to size constraints.

For testing, you can:
1. Use the built-in **Demo Mode** in the UI (no video needed)
2. Record a short video with your webcam
3. Download from FaceForensics++ or similar research datasets (for research use only)
